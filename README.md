# Новичок

Чек-лист первой смены комплектовщика склада. Если новичок застрял, наставник видит, на каком шаге возникла проблема, и оставляет ответ. Все люди, события и задачи в приложении вымышлены.

## Запуск

Нужен Python 3.13.

```sh
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn main:app
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Файл SQLite создаётся при первом запуске в `data/shift.sqlite3`. Путь можно задать через `DB_PATH`.

## Сценарий для проверки

1. Нажмите «Начать демо». Отметьте первые два шага выполненными.
2. В шаге «Войти в терминал» нажмите «Нужна помощь» и напишите «Терминал сообщает, что у меня нет доступа».
3. Откройте «Наставник» в отдельной вкладке. Убедитесь, что запрос содержит имя, шаг, время и заметку. Ответьте «Доступ выдан, войди повторно» и закройте запрос.
4. На экране новичка нажмите «Обновить». Прочитайте ответ, отметьте вход в терминал и учебный заказ выполненными. Прогресс должен стать **4 из 4**.
5. Перезапустите приложение. По прежней ссылке должны остаться прогресс и ответ наставника.

«Начать демо» каждый раз создаёт отдельную смену. Обе ссылки относятся к одной смене и доступны всем, у кого они есть. В демо используйте только вымышленные сообщения.

## Размещение на Railway

Подключите репозиторий к одному веб-сервису Railway, подключите постоянный диск по пути `/data` и задайте `DB_PATH=/data/shift.sqlite3`. Railway автоматически запускает `main:app`. Готовность приложения можно проверить по адресу `/health`. Публичный адрес выдаёт **Generate Domain** в настройках сети сервиса.

## Границы демо

`DEMO-1042` обозначает вымышленную задачу о приёме. Чек-лист, прогресс и запросы хранятся в SQLite. Обмен данными с Битрикс24 и учётные записи пользователей потребуются для пилота с реальными сотрудниками.
